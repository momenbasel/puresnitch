## التثبيت

```bash
brew tap momenbasel/puresnitch
brew trust --tap momenbasel/puresnitch
brew install --cask puresnitch
```

يرفض Homebrew 6 تحميل أي cask من صنبور خارجي قبل الوثوق به، لذلك يلزم تنفيذ سطر `brew trust` مرة واحدة فقط. للتحديث لاحقًا استخدم `brew upgrade --cask puresnitch`.

أو نزّل ملف الـ `.dmg` الموقّع والموثّق من [صفحة الإصدارات](https://github.com/momenbasel/puresnitch/releases/latest) واسحب PureSnitch إلى مجلد `/Applications`.

## لماذا PureSnitch

Little Snitch هو المعيار الذهبي لجدار الحماية على نظام macOS، لكنه برنامج تجاري مدفوع. LuLu مجاني لكنه يفتقر إلى الخريطة العالمية ومدير القواعد المتقدم. جدار الحماية المدمج في macOS يحجب الاتصالات الواردة فقط ولا يفعل شيئًا للاتصالات الصادرة.

PureSnitch يقدّم الخيار الرابع:

- **نفس واجهة Little Snitch 6** — عنصر شريط القوائم، خريطة العالم، مدير القواعد، تنبيهات الاتصالات.
- **مفتوح المصدر بترخيص MIT** — اقرأ الكود، عدّله، شاركه.
- **بدون تتبع** — لا تحليلات، لا تقارير أعطال ترسل إلى الخارج.
- **مبني محليًا باستخدام SwiftUI** — تطبيق Mac حقيقي، ليس نسخة منقولة.
- **موقّع بشهادة Developer ID وموثّق من Apple** — بدون تحذيرات Gatekeeper.

## المميزات

- مراقب للاتصالات الحية وإجماليات النطاق الترددي لكل عملية؛ لا يتضمن الإصدار الحالي تحديد الموقع الجغرافي الحي أو عدد البايتات لكل اتصال
- متصفح قواعد لعرض القواعد المخزنة والبحث فيها وتفعيلها أو تعطيلها وحذفها؛ في v0.2.1 لا يمكن إنشاء قاعدة دائمة جديدة إلا من تنبيه وكيل DNS
- DNS over HTTPS إلى Cloudflare أو Quad9 أو Google أو أي خدمة DoH تختارها
- وكيل DNS تجريبي على الحلقة المحلية، لا يعمل إلا للعملاء الذين تضبطهم يدويًا ولا يغيّر إعدادات DNS في macOS
- حجب النطاقات عبر قوائم 1Hosts و OISD و StevenBlack و HaGeZi للعملاء المضبوطين يدويًا لاستخدام وكيل DNS التجريبي فقط
- حجب على مستوى عناوين IP والمنافذ عبر مرساة `pfctl`
- ملفات التعريف (افتراضي، منزل، واي فاي عام، إغلاق محكم) محفوظة للتنظيم فقط؛ يطبّق الإصدار الحالي الملف الافتراضي وحده ولا يمكن تفعيل الملفات الأخرى، كما أن التبديل التلقائي حسب الشبكة غير متاح
